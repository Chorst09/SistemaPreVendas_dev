# Imagens da Proposta

## Cabeçalho e Rodapé

Adicione as imagens do cabeçalho e rodapé nesta pasta:

### Cabeçalho (Header)
- **Nome do arquivo**: `header.png` ou `header.jpg`
- **Dimensões recomendadas**: 1920x200px (largura x altura)
- **Conteúdo**: QR Code, informações de contato, endereço, telefone
- **Formato**: PNG (preferencial) ou JPG
- **Posição**: Topo de todas as páginas internas (a partir da página 4)

### Rodapé (Footer)
- **Nome do arquivo**: `footer.png` ou `footer.jpg`
- **Dimensões recomendadas**: 1920x320px (largura x altura)
- **Conteúdo**: Logo Double TI + Telecom, barra colorida superior
- **Formato**: PNG (preferencial) ou JPG
- **Posição**: Base de todas as páginas internas (a partir da página 4)

## Como Extrair as Imagens dos Prints

1. Abra os prints originais em um editor de imagens (Photoshop, GIMP, etc.)
2. Selecione e recorte apenas a área do cabeçalho
3. Salve como `header.png` com fundo branco
4. Repita o processo para o rodapé e salve como `footer.png`
5. Coloque ambos os arquivos nesta pasta

## Dicas

- Use PNG para melhor qualidade
- Certifique-se de que o texto está legível
- Mantenha as proporções originais
- Se necessário, aumente a resolução para impressão (300 DPI)
